# Opening Range Breakout (ORB) Strategy Analysis

## Overview
Over the last few weeks, I worked on a personal project focused on systematic trading and strategy development.

This project explores a rule-based intraday trading strategy using the Opening Range Breakout (ORB) concept across ~30 Nifty stocks.

---

## Strategy Logic
- 30-min Opening Range (9:15–9:45)
- VWAP filter
- ADX momentum filter
- Volume confirmation
- Risk Reward Ratio: 2.5:1

---

## Results
- Portfolio Return: ~14%
- Best-performing stocks: +40%+
- Weak-performing stocks: -15%

---

## Challenges Faced
- Small changes in code caused major differences in results
- Same strategy behaved differently across stocks
- Range-bound markets reduced consistency

---

## Key Insight
Performance depended more on stock selection and market conditions than the strategy itself.
